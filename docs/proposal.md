### Requirements every idea must meet

From the course and the [grading criteria](course/project/grading-criteria.md):

- [ ] **Clear target group** and a **clear benefit** for them
- [ ] Builds interactive features on top of an **existing API** (real data)
- [ ] Creates **added value** from the API data. It must not be a "dinner planner in disguise" that only collects and summarises items (that caps the grade at E).
- [ ] Has app-specific data that we **persist per user** (Firebase), so it needs login
- [ ] Fits the **MVP** architecture: several presenter/view pairs we can split between 4 people
- [ ] **Original**: not a copy of a [previous year's project](course/project/hall-of-fame-examples.md)
- [ ] Not too big for ~20 h/week/person in one period
- [ ] The API is free or under 200 SEK, works from the browser or via the course proxy, and we can get a key quickly

Bonus points toward an A plus: an original idea (beyond state of the art), combining several APIs, live sync across devices, or collaborative features between users.
