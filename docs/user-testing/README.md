# User testing

The final submission requires "documented user feedback and how it was acted upon" ([03-project-submission.md](../course/deliverables/03-project-submission.md)).

Add one file per test session: `YYYY-MM-DD-<what>.md`, e.g. `2026-11-28-paper-mockup.md`. Put pictures in `img/`.

How much testing each grade needs ([grading criteria](../course/project/grading-criteria.md), usability):

| Grade | Documented user consultation |
|---|---|
| C | One 30 min session at the prototyping **or** evaluation stage, plus the improvements we made |
| B | 30 min prototyping **and** 30 min formative evaluation (or 2×30 min formative), plus the improvements |
| A | At least 30 min at the prototyping stage **and** 30 min of formative evaluation, with **creative** improvements |

Testers should come from our **target group**. Write down how long each session took.

## Template

```markdown
# <What was tested>, <date>

- **Version:** paper mock-up / Figma / deployed build (commit or URL)
- **Testers:** 3 people, e.g. "classmate, non-CS friend" (no full names)
- **Tested by:** <who ran the session>

## Tasks we asked them to do
1.
2.

## What we observed
-

## What we changed because of it
- <change> → <PR/commit link>
```
